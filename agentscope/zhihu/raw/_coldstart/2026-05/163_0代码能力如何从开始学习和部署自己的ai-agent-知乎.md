具体操作步骤
第一步：注册登录。 打开扣子官网，用手机号注册即可。
第二步：创建 Bot。 点击”创建 Bot”，给它起个名字，比如”我的阅读助手”。
第三步：写人设提示词。 这是最核心的一步。你需要用自然语言告诉 AI 它是谁、该怎么表现。比如：
你是一个阅读笔记助手。当用户给你发送一段文字或一篇文章链接时，你需要：
1. 总结文章的核心观点（不超过3条）
2. 提取关键数据和论据
3. 用一句话给出你的评价
语气要求：简洁、直接、不说废话
第四步：添加插件（工具）。 扣子内置了几十个插件——网页浏览、图片生成、代码执行、数据分析等。你只需要勾选想用的插件，Agent 就自动获得了这个能力。比如勾选”网页浏览”插件，你的阅读助手就能直接帮你读网页内容。
第五步：添加知识库。 如果你想让 Agent 基于特定资料回答问题（比如你自己的读书笔记、公司文档），把文件上传到知识库就行。支持 PDF、Word、TXT 等格式。
第六步：测试和发布。 右侧有个对话窗口，直接跟你的 Agent 聊天测试。满意了就点发布，可以发布到豆包、飞书、微信等平台。
整个过程不需要写一行代码。从注册到发布，快的话 30 分钟就能搞定。
四、进阶一步：用 Dify 搭建带工作流的 Agent
Coze 能满足大部分简单场景。但如果你想做更复杂的事情——比如让 Agent 先搜索网页、再总结、再翻译、最后发邮件——你需要一个支持”工作流编排”的平台。
Dify 就是目前最适合零代码用户的工作流 Agent 平台。它是开源的（代码在 GitHub 上），同时也提供云端版本，注册就能直接用。
Dify 跟 Coze 的区别
维度	Coze（扣子）	Dify
核心能力	单轮/多轮对话Bot	工作流编排 + 对话Bot
操作方式	配置表单	拖拽式流程图
适合场景	问答助手、客服	多步骤自动化、数据处理流水线
模型选择	字节内部模型为主	支持几乎所有主流大模型（GPT-4、Claude、通义千问等）
部署	平台托管	云端版 + 可以自部署到自己服务器
知识库	文件上传	文件上传 + 网页抓取 + API导入
你能用 Dify 做什么？
举一个真实的例子。假设你是一个产品经理，每天需要看竞品动态。你可以在 Dify 里搭建一个工作流：
1.每天早上自动去指定的几个网站抓取新内容
2.用大模型对内容做摘要和分类
3.筛选出跟你关注的关键词相关的内容
4.生成一份结构化日报
5.通过 webhook 推送到你的飞书/钉钉群
