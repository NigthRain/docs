# 怎么看 Cursor 品牌将被淡化,新项目都转移 Grok,AI IDE 已经推出历史舞台了吗? - 知乎

> Kitt在进化 | 2026-08-08 14:45

来源: https://www.zhihu.com/question/2069376898556340193/answer/2069434159081247795?utm_medium=openapi_platform&utm_source=1a2112

---

Cursor这样的AI IDE，是vibe coding第一阶段的产物。IDE形态，编辑器里嵌入AI、Tab补全，后面又加上了Agent功能。
第二阶段转向TUI，以Claude Code CLI为代表，直接跑在终端里，IDE不再是必须的。
第三阶段是桌面应用形态，以Codex为代表。不再局限于编辑器或终端，而是直接操控整个桌面环境，还支持Computer Use，截屏→像素级分析→鼠标键盘操作。WorkBuddy、TRAE这些国产产品，GitHub Copilot和Cursor也都另做了类似Codex的UI，包括Antigravity也全面转向这个形态。一眼看过去大家都在抄Codex。
到这里，一个很有意思的问题就出现了，这是最终形态吗？
现在各个模型厂商都在抓紧出Harness，Grok的Grok Build，Meta也出了Meta Code，DeepSeek的Harness产品也据说快发布了。很多人简单理解成这是在抢coding市场，这样理解的话你很难解释为什么他们现在才有动作。
真正的逻辑是，Harness是AI达成下一阶段的关键入口。可以参考这篇文章：
简单来说，就是让AI迭代自身权重还做不到，那么现在能做的就是让AI迭代Harness。
有人就要说了，那不就是让Opus修改Claude Code代码这么个事吗，A/早就在做了啊？
