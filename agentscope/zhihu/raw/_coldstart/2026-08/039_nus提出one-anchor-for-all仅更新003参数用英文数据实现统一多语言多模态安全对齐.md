# NUS提出One Anchor for All:仅更新0.03%参数,用英文数据实现统一多语言多模态安全对齐 - 知乎

> 我爱计算机视觉 | 2026-08-10 09:10

从神经元数量与攻击成功率ASR的关系来看，两者呈现明显负相关：某种语言拥有的MLS-Neurons越多，模型在该语言上的ASR通常越低，说明共享安全神经元的规模与模型安全性紧密相关。
作者还分别屏蔽随机神经元、语言特定安全神经元和真正的MLS-Neurons。结果显示，屏蔽MLS-Neurons后，两类风险场景中的攻击成功率上升最明显。
以Qwen为例，屏蔽MLS-Neurons后，图像主导风险ASR从 30.71 升至 50.44，文本主导风险从 19.57 升至 50.98。与此同时，MMMU和MGSM上的变化仅为 0.22 和 0.92。
这意味着移除这组神经元会显著破坏安全能力，却几乎不影响一般多模态理解和多语言推理能力，进一步证明MLS-Neurons确实承担了较为集中的安全功能。
多语言多模态安全防护
论文在Gemma-3-4B-Instruct、Qwen3-VL-8B-Instruct和Llama-3.2-11B-Vision-Instruct三种模型上开展实验，覆盖不同参数规模与模型架构。
安全评测共覆盖10种语言：中文、英文、法语、德语、日语和西班牙语作为分布内语言，阿拉伯语、挪威语、芬兰语和俄语作为分布外未见语言；两类设置分别为图像主导风险IR与文本主导风险TR。指标为攻击成功率ASR，数值越低代表模型越安全。
对比方法涵盖原始模型，以及具有代表性的多语言安全对齐和多模态安全对齐方法。为进一步分析不同参数更新策略的影响，论文还比较了全量监督微调、LoRA，以及在相同层分布下随机选取等量神经元进行训练的方案。除安全性外，作者还使用MMMU、MGSM和MM-Vet，分别评估模型的多模态理解、多语言推理能力，以及对良性请求的正常回答能力。
在三种模型、两类风险设置中，本文方法的平均ASR均为最低。相较原始模型，Llama的IR/TR平均ASR从 24.01 / 14.65 降至 5.89 / 2.80，Qwen从 27.71 / 18.43 降至 8.07 / 5.86；在Gemma上，相较当前最强基线MLC，ASR从 10.58 / 10.55 降至 6.09 / 5.73。
定量结果之外，论文还给出了跨语言、多模态复合攻击的定性案例。原始模型会直接生成危险内容，而经过MLS-Neurons定向训练后，模型能够识别不同语言与图像中的风险，并给出安全拒答。
作者进一步将MLS定向训练与全量微调、LoRA和随机稀疏更新进行比较。
