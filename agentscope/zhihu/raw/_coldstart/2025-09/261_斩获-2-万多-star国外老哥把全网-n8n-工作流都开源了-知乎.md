n8n 是国外最火的开源自动化工作流神器，没有之一。
在 GitHub 上斩获了惊人的 130 K+ 的 Star。
n8n 是一个自动化工作流搭建平台，你不需要写代码，只需要拖一拖、点一点就像搭积木一样，就能把一个个节点串起来。
然后这些串起来的节点就能完成你设定的某个任务。
今天不是重点介绍这个工作流平台，之前逛逛 GitHub 推荐过。感兴趣的滑到本文章的最底部，看看之前写的 n8n 相关文章。
01、项目简介
今天推荐的是一个很火的 n8n 工作流大合集。
都知道 n8n 发挥它的作用，需要你把配置一个个的节点，而且需要把它们按照你预期的效果串联起来。
而今天推荐的开源项目：n8n-workflows 就有很多现成的工作流模板，不需要你一个个手动配置节点了。
这个叫 Eliad Shahar 的国外老哥把全网能找到的实用 n8n 工作流都整理打包好了，一共 2053 个。
而且按照功能场景或者节点工具分好类，每一个工作流都通过 json 文件提供，导入到平台就能用。
更绝的是，这个开源大合集配备了一个非常强大的本地文档搜索系统。
用 Python 和 SQLite 数据库搭建了一个本地服务。
运行起来后，你在浏览器里就能：输入关键词（比如发票、AI），它能毫秒级地从两千多个模板中找到匹配项。
