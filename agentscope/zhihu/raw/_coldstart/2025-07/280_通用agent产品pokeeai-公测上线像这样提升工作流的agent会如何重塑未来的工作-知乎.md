# 通用Agent产品Pokee.AI 公测上线,像这样提升工作流的Agent会如何重塑未来的工作? - 知乎

“你们之前团队只有4个人？这产品是怎么做出来的？”
这是过去一周我被问最多的问题。 
从无人看好到1200万美元融资，我们如何用7个月证明AI Agent的未来？
我是朱哲清（Bill Zhu），Pokee AI的创始人，前Meta AI应用强化学习团队负责人。去年10月，当我带着“用AI Agent自动化一切工作流”的梦想开始创业时，没人相信这个未来。当时的硅谷还沉浸在LLM的热潮中，投资人听到“强化学习”“多工具协同Agent”时，表情就像在看一个科幻PPT：“太超前了，等风口来了再说吧。” 大家都在观望，没有人真正敢下注的。很多投资人连续找我聊了5轮，最后还是没敢下手，实在太早了。后来有几家一线美国基金的合伙人跟我说，我们提出这个大方向的重要性比市场共识早了近半年。 
从4人到6人，一场与时间的赛跑 
最初的团队只有4个人，当我们当的大方向不被市场看好时，每天的例会上争论的问题是：用户到底需要什么？ 我们试过垂直场景的AI工具，也做过单点自动化插件，但始终找不到PMF（产品市场契合点），用户对于垂类场景的模型和产品始终得不到真正的Aha moment。
转机出现在今年年初。我们决定回归初心——放弃小功能，专注做一个“能理解人类意图、自主调用20+平台上千工具完成复杂任务”的通用AI Agent。团队不分昼夜地重构代码，用强化学习优化多步骤规划，甚至自己成了“人肉测试机”：每天模拟上百种用户指令，从写邮件到分析数据，再崩溃也要笑着改Bug。 
融资逆袭，从冷板凳到超额认购 
北京时间3月12日，我们在Manus发布他们的邀请码两天前，发布了我们的第一款demo，真实展示了我们横跨多平台，上千工具的执行和推理能力。AI Agent风口开始起飞，一年前我还在Meta带着应用强化学习团队，一年后小扎到处开天价挖人。我们30分钟内就让硅谷传奇Intel CEO兼Walden International主席 Lip-bu Tan给我们写了超大的Angel Check。4月28日，我们的research preview正式上线，2天内收到多份头部基金TS，3倍超额认购，最终斩获1200万美元种子轮，Point72 Ventures、高通、三星等巨头都挤了进来。 
5个月，20+工具整合，数据说话 
4月底内测上线时，团队已扩充到6人。
我们接入了Google全家桶、Meta平台、GitHub等20多个平台的上千个工具，用户只需一句话，Pokee就能自动完成Google Slide制作、跨社媒平台AI视频图片内容发布、数据分析，Overleaf写论文，发布Github Pages网站等任务。
