3. 阿里千问办公：三合一的新变量
7 月 21 日，阿里把 QoderWork、悟空、MuleRun 三款 Agent 合并成“千问办公”。合并前 QoderWork 月访问量 788 万排第三，悟空一直半成品状态，MuleRun 主攻海外已覆盖 43 个国家。
合并后的千问办公走“钉钉+阿里云全链路打通”路线，能力融合听起来不错——QoderWork 的桌面执行 + 悟空的企业工作台 + MuleRun 的跨平台引擎，通义千问多模态能力兜底。但产品刚合并，三拨人马各自为战太久了，融合体验得打个问号。

二、编程智能体：最赚钱的赛道
编程 Agent 商业化最成熟。Cursor 和 Claude Code 走了两条完全不同的路线——一个把 AI 塞进 IDE 的每个角落，一个让终端变成全自动编程工厂，但都赚得盆满钵满。
4. Cursor：AI IDE 的标杆
Cursor 估值 500 亿美元，年营收约 20 亿美元，是目前最成功的 AI 编程 IDE。基于 VS Code 架构深度改造，Tab 补全的准确率是我用过最高的，代码上下文理解行业领先。
Agent 模式（Composer）支持多文件联动编辑、自动跑测试、修复错误，基本做到“你说一句，它改一片”。模型可以灵活切换 GPT-4.1 / Claude 4 / Grok 4.5。插件生态完全兼容 VS Code，迁移成本几乎为零。
贵是真贵：Pro 版 20 美元/月，Business 版 40 美元/月。但如果你每天写代码，这笔钱一周就能回本。
