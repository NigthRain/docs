# AI如何辅助编程? - 知乎

如今，我已养成习惯，会在每天晚上都会在睡前用一用AI，让AI把我脑子中的想法变成现实。
AI编程工具
目前主流的AI编程工具有Codex（由OpenAI开发），Claude Code（由Anthropic开发），Cursor等。
这里需要区分两个概念：AI 编程工具和 AI 大模型。以 Codex 为例，它是 OpenAI 推出的AI编程工具，可以免费使用。而调用的AI大模型则由谁提供，谁收费。用户可以使用 OpenAI 的模型，也可以调用其他公司的大模型（如deepseek）。
Claude Code 也是如此：它是 Anthropic 开发的AI编程工具，工具本身可以免费使用，既能接入其他模型的 API，也能调用 Anthropic 自研的模型。Anthropic 的自研模型在编程方面是目前所有AI模型中公认表现最好。不过，Anthropic 公司的经常做一些让人反感的公关行为，因此，我更倾向于使用 OpenAI 的 Codex。
除此之外，其他公司如Kimi（最近推出的K3大模型在前端代码设计取得了全球第一的成绩），也都有类似的AI编程工具。
从2025到2026年，AI编程最直观的变化就是编程工具的默认界面不一样了。
2025上半年，我还在用工具Cursor编写的项目 流金沙漏的时候，AI编程工具的页面还是代码编辑器，整个页面是代码为主，AI聊天的对话框显示在另一侧，作为辅助。
而2025下半年开始，Agent（智能体）编程概念逐渐兴起，AI不再是简单的问答工具，而是作为智能体，使用各种插件和技能，统筹规划全局。AI编程工具默认的主页从代码编辑器变成了聊天对话框。现在最新版本的Cursor，默认只展示聊天框，需要点右上角的IDE才会切换到代码编辑器界面。
同理，当我第一次使用工具Codex的时候，我第一个疑问就是：代码编辑界面在哪？事实上，Codex本身连代码编辑器都没有。要是想改代码，用户要自己运行别的代码编辑器，比如VS Code或Cursor。
除了图形界面，这类 AI 编程工具通常也支持纯命令行模式。以 Claude Code 为例，只需在终端输入 claude，就能让它修改当前目录下的项目。
关于Code Plan
大模型公司一般都会提供Code Plan订阅套餐，以 OpenAI 的为例，套餐月费从 8 美元到 200 美元不等。
套餐价格越高，可使用的 token 也越多。
