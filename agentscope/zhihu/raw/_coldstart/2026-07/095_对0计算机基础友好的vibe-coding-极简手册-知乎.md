# 对0计算机基础友好的Vibe Coding 极简手册 - 知乎

> 毒Sir | 2026-07-29 12:26

引言：不讲提示词，直接出操作手册
2025 年初，OpenAI 的前研究．总监 Andrej Karpathy 在一条推文里随手造了一个词：Vibe Coding。他的原话是：有一种新的编程方式，我称之为“氛围编程”，就是完全沉浸在氛围中，拥抱指数级增长，忘记代码的存在。这之所以可能，是因为大型语言模型（比如 Cursor Composer 搭配 Sonnet）变得太强大了。而且我只是用 SuperWhisper 和 Composer 对话，所以几乎都不碰键盘。我会要求一些最愚蠢的事情，比如“把侧边栏的内边距减半”，因为我懒得去找。我总是“全部接受”，不再阅读差异对比。当我收到错误消息时，我就直接复制粘贴进去，不加任何注释，通常这样就能解决问题。代码的增长超出了我平时的理解范围，我得真的花时间仔细阅读才能搞明白。有时候大型语言模型无法修复一个 bug，我就绕过去，或者要求随机更改，直到问题消失。对于周末的临时项目来说，这样还不错，但仍然相当有趣。我在构建一个项目或网络应用，但这其实算不上编程——我只是看东西、说东西、运行东西、复制粘贴东西，大部分时候都能正常工作。
这个词一出来就炸了，然后像所有热点一样迅速被嚼烂、神化甚至污名化。Andrej Karpathy 自己后来不得不出来补了一句：「某种强大的外星工具被分发给了大家，但没有任何使用手册，九级地震正在撼动整个职业。」
而这篇教程正好就想成为Karpathy所说的使用手册。我将结合自己这两年以来累计半年多的实战经验，试图总结必要的经验并用最简单易懂的语言来阐述。如果你点开这篇文章，我将笃定你大概率是这么一种人：不是程序员，可能连命令行都不知道是什么；但听说了 Vibe Coding 这件事，你想试试，想知道一个计算机知识为零的人，到底能不能用这套东西做出真能用的小工具——不是那种游戏玩具——给自己和给一小群人解决痛点的那种"大杀器"。
我的答案是：能。但「能」不等于「躺着就能成」。
Vibe Coding 对零基础的人确实友好，比传统的编程学习友好太多了。
编程为什么难？
一方面是因为它本身的确是有相对高的门槛，所涉及的知识体系也非常庞杂；另一方面是它离普通人的工作太过于遥远，你不能指望一个在办公室里编写文案和整理表格的前台，也能熟练使用Pandas、NumPY等等去处理以亿为单位的海量数据。
都说隔行如隔山，但编程对于普通人来说，完全就是另一个宇宙。
