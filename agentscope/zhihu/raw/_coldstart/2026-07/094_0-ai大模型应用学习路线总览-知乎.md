# 0-AI大模型应用学习路线总览 - 知乎

> Mingdeng Yue | 2026-07-29 15:46

来源: https://zhuanlan.zhihu.com/p/2065824592032174749?utm_medium=openapi_platform&utm_source=1a2112

---

AI 最有价值的方向不是单纯做工具，而是“AI + 行业”。例如 AI 游戏 NPC、AI 科研、AI 生物、AI 医疗、AI 自动驾驶、企业智能助手等。真正产生商业价值的是解决具体行业问题。
目前 AI 应用开发重点集中在几个方向：
Agent（智能体） 是未来重点，包括 AI 助手、客服、数字人、办公自动化等。核心技术包括 Function Calling、Tool 调用、MCP、工作流以及 LangChain、LangGraph、Qwen-Agent、Dify 等框架。
RAG（知识库增强） 是企业落地最成熟的方向，通过企业文档、数据库、知识库，让大模型回答企业内部问题。
Text2SQL 是另一个重要方向，让用户通过自然语言查询数据库，但需要注意 SQL 安全、权限控制和数据污染问题。
AI 开发技术路线
普通开发者不需要训练大模型，重点应该放在 AI 应用开发。
学习路线：
Python 基础 → 调用大模型 API → Prompt → RAG → Agent → 企业应用部署。
API 调用是目前最推荐方式，例如阿里云百炼提供 DASHSCOPE_API_KEY，可以快速调用 Qwen、DeepSeek 等模型。
本地部署适合数据安全要求高的企业，但受到 GPU 限制。
