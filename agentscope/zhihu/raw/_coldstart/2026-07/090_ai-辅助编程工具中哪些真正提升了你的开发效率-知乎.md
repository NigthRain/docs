# AI 辅助编程工具中,哪些真正提升了你的开发效率? - 知乎

> BulkPictools | 2026-07-30 00:30

每天通勤2小时+，电动车转地铁，我在手机上完成了大部分开发决策。
不是演示，是我每天在做的事。
先说结论
碎片时间做决策，整块时间做执行。
我用一套免费方案，把 Claude Code 从电脑前搬到了手机上。现在可以随时随地安排任务、跟踪执行、修复bug。
我的场景
身份：兼职独立开发者，白天上班，晚上带娃
痛点：
・真正能坐在电脑前的时间，可能一天就1-2小时
・回到家还要帮忙带娃，没法一直对着电脑
・产品需要持续迭代，但时间有限
目标：利用碎片时间，完成开发决策和任务安排
我的免费方案
核心思路
把 Claude Code 从电脑前搬到手机上。
技术方案：
1.在家里的 mini 主机上运行 Claude Code
2.通过 Tailscale 将本地 IP 映射到外网
3.通过外网 IP + 端口号，以 web 形式访问 Claude Code
4.手机上通过浏览器访问，随时随地使用
成本：
・Token 费用：免费版够用
・电费：mini 主机 24 小时运行，电费可忽略
・其他：全部免费
我用的工具
AI 工具：
・Claude Code：主力工具，用于代码生成、任务安排、问题修复
・DeepSeek：辅助工具，用于聊天、信息获取
远程连接：
・Tailscale：免费，将本地 IP 映射到外网
・终端工具：通过外网 IP 连接到 mini 主机
语音输入：
・微信语音识别：对着文件传输助手说话，识别后直接使用
部署：
・GitHub：代码托管
・Cloudflare Pages：自动部署
我的实际工作流
场景1：通勤时间安排任务
时间：早上电动车 + 地铁上，约1小时
做法：
1.打开手机浏览器，访问 Claude Code web 界面(外网IP + 端口号)
2.告诉 Claude 今天要做什么功能
3.让 Claude 拆解任务、生成代码框架
4.审核 Claude 的输出，安排执行
效果：到公司前，今天的任务已经安排好了。
场景2：发现bug立即修复
时间：上班前、午休时、通勤时
案例：
・上班前提交代码到 GitHub
・Cloudflare 自动拉取部署
・发现部署失败，有 bug
・在手机上定位问题
・让 Claude 修复 bug
・重新提交，自动部署
