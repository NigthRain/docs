# 为什么在性能相近的情况下,DeepSeek模型的影响力比Qwen模型更大? - 知乎

还记得那句话吗：打败口香糖的是手机上的抖音，打跑方便面的是外卖平台。现在，真正让美国 AI 巨头心生恐惧的，不是另一个卖 API 的 OpenAI，而是中国的量化巨头与电商云厂商。
详细的可以看一下发生的时间列表：
2023年：百模大战与大语言模型的爆发
・OpenAI (GPT): 3 月发布 GPT-4，奠定了其在行业内绝对的技术领先地位，多模态能力初现端倪。
・Google (Gemini): 年底压轴发布 Gemini 1.0（Nano, Flash, Pro, Ultra），试图在原生多模态领域硬刚 GPT-4。
・Anthropic (Claude): 相继发布 Claude 1 和 Claude 2，以超长上下文窗口（Context Window）和极其严谨的安全对齐（Safety Alignment）打出差异化优势。
・Meta (Llama): 发布 Llama 1 和 Llama 2，彻底点燃了开源社区的热情，成为了全球开源大模型的基础底座。
・阿里 (Qwen): 推出第一代 Qwen (千问) 系列（如 7B, 14B, 72B），在中文能力和多语言评测上迅速跻身第一梯队。
・DeepSeek (深度求索): 年底崭露头角，发布 DeepSeek Coder 和 DeepSeek-LLM，从一开始就展现出在代码编写和数理逻辑上的深厚功底。
・字节跳动: 内部测试云雀（Skylark）等模型，处于蓄力期。
2024年：多模态深化、开源逆袭与价格战
・OpenAI: 发布原生多模态模型 GPT-4o（极低延迟语音交互）以及首个侧重系统性思考的推理模型 o1，开启了“System 2”慢思考时代。
・Anthropic: Claude 3 家族（Opus, Sonnet, Haiku）惊艳亮相，其中 Claude 3.5 Sonnet 凭借卓越的代码生成能力，成为了全球开发者的首选工具。
・Google: 推出 Gemini 1.5 Pro，将上下文窗口史无前例地拉升至 100 万到 200 万 token，主打海量文档和长视频的瞬时解析。
・Meta: Llama 3 及 Llama 3.1（最高 405B 参数）发布，直接将开源模型的性能拉升至 GPT-4 级别。
・阿里 (Qwen): 密集发布 Qwen 1.5 及 Qwen 2/2.5 系列，横扫各大全球开源榜单，并在数学和代码能力上表现抢眼。
・DeepSeek: 发布 DeepSeek-V2 和 V3，采用 MoE（混合专家）架构，以极其夸张的性价比和训练效率震惊业界，V3 性能直逼海外顶级闭源模型。
・字节跳动: 正式推出豆包（Doubao）大模型家族，并发起史无前例的“API 价格战”，凭借极低的调用成本和强大的 C 端产品矩阵（如扣子 Coze）迅速抢占国内市场份额。
