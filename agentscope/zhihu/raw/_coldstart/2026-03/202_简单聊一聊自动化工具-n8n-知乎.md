# 简单聊一聊自动化工具 n8n - 知乎

> 独元殇 | 2026-03-10 22:20

来源: https://zhuanlan.zhihu.com/p/2014827945261298841?utm_medium=openapi_platform&utm_source=1a2112

---

如果你要创业开一人公司，那你必须得知道自动化工具，来应付你复杂的业务逻辑。
看 dify n8n coze llamaindex langchain ，这些都是自动化工具，不过 自动化 是一门技能，意思是说，你如果没有尝试过，就不会体会到自动化的好处。一般人如果没有刻意试过，那么都不会接触到自动化，包括程序员。
这些功能都差不多，比较出名的是 n8n ，其次是 dify 。我有略尝试过 n8n。
n8n 会更「正统」一点
在海外，自动化爱好者，一般都是推荐 n8n 。给我的感觉就是 n8n 会更「正统」一点。
就是设计一个工作流，让多个程序、服务，能相互联系起来，你可以因为一个邮件、短信，然后把数据处理后储存到谷歌表格里。
不用，感觉这些东西都可以用 python 写个脚本就行，一用，就会被吸引住，然后会逐渐变成自动化爱好者。
其他几个不知道，这个 n8n 是开源的，可以自己托管，也就是放到自己的服务器上运行，数据完全是自己的。自己掌控。
海外的东西比较全
然后 n8n 的构建很直观，像海外经常用的 Gmail 、谷歌表格 这种公开 API 的东西，它都给定制好了。直接拖动即可。如果功能没实现，那么 js python 脚本也可以自定义。
对于出海、依赖海外生态的人，这里面弄的还比较全，比如 处理邮件的 Gmail 和 Outlook、整理信息的 Notion、作为简易数据库的 Google Sheets、通讯工具 Slack 或 Discord，甚至还包括 Markdown 处理器、RSS 订阅和 webhooks ..... 跟 Mac 的【快捷指令】一样，都是一个个节点，可以直接拖进来。
其实这些工具都差不多，区别就是支持的生态不一样，n8n 的生态更全，而扣子不能存谷歌表格，而是飞书表格。扣子里面还有知乎的东西。
在 n8n 上，如果熟悉一下传说中的【自动化】，体验一下甜头，那么你就会马上迸发无数的可能性。
