Cornucopia Multi-Agent：从「单兵作战」到「集群协同」的生产级实践
从一个真实痛点说起
过去一年，几乎每个 AI 应用开发者都写过类似的代码：
一个 prompt 进去，一段文本出来——这确实能用，但很快就碰到了天花板。你想让它上网搜索最新财报，做不到；你想让一个 Agent 分析财务，另一个写报告，做不到；你想让多个 Agent 先辩论、再达成共识、最后出报告——更是天方夜谭。
于是大家开始往代码里塞越来越多的逻辑：先调一次搜索 API，再把结果喂给 LLM，再手动拼接输出，再判断质量是否达标……代码越来越长，越来越像一团意大利面。
这不是你的问题，是工具的问题。 你需要的是一个开箱即用的多智能体协作框架，而不是每次都从零搭建脚手架。
Cornucopia：一个名字就很有野心的项目
Cornucopia，希腊神话中的「丰饶之角」、中国古代传说中的「聚宝盆」——什么都能从里面倒出来，最终收获财富。这个项目也确实对得起这个名字：6 种协作模式、6 种通信拓扑、4 条执行路径、8 个专业工具，外加一个 Streamlit 可视化界面和完整的 FastAPI 服务层。
先说结论：它可能是目前中文社区里功能最完整的轻量级多 Agent 框架之一。
架构：从单 Agent 到集群的全能力谱系
很多框架只覆盖了多 Agent 的某一个切面。比如有的只做顺序调用链，有的只做辩论，有的只做规划。Cornucopia 的思路不同——它提供了一条从简单到复杂的完整能力谱系：
每条路径对应不同的复杂度需求。简单的任务不用大炮打蚊子，复杂的任务也不会捉襟见肘。
路径一：简单执行——够用就好
适合明确知道要干什么、只需把几个 Agent 串起来的场景。支持 6 种预定义协作模式：
模式	一句话说明	典型场景
顺序传递	A 的输出是 B 的输入	调研→分析→报告
并行处理	多 Agent 同时跑，结果合并	多角度分析同一问题
辩论共识	多轮辩论，收敛到共识	投资决策、方案评估
专家团队	Research→Analysis→Writing 流水线	结构化报告生成
评论审核	写→审→改→再审	内容质量打磨
层级协作	主管分配，下属执行	复杂任务分解
路径二：LLM 协作——Agent 直接对话
这条路径更轻量，跳过了 Agent 类的封装，直接调 LLM：
辩论共识是我最喜欢的模式——给 LLM 设定对立立场，让它们互怼几轮，最后由一个”主持人”角色总结共识。
